# Service Ticket Management App

A simple web application for creating and tracking service tickets.

## Features

- Create service tickets
- View tickets
- Track ticket status
- Simple dashboard interface

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

service-management-app
│
├── index.html
├── app.js
└── style.css

## How It Works

Users can create a service ticket with:

- title
- description

Tickets are stored in the browser and displayed in a list.

## Running Locally

Open index.html in your browser.
